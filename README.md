# CS-MRI-CORE

## Parameter-Efficient Cross-Slice Adaptation of an MRI Foundation Model for Extreme Few-Shot Meningioma Segmentation

CS-MRI-CORE is a research project focused on parameter-efficient adaptation of MRI foundation models for extreme few-shot brain tumor segmentation.

The project investigates cross-slice contextual information to improve segmentation performance under limited annotated medical imaging data conditions.

---

## Overview

Medical image segmentation models often require large-scale annotated datasets. However, in clinical scenarios, obtaining pixel-level annotations is expensive and time-consuming.

This project explores an efficient adaptation strategy for MRI foundation models using limited training samples while preserving meaningful anatomical context across MRI slices.

---

## Research Objectives

- Developing a parameter-efficient adaptation framework for MRI foundation models
- Investigating cross-slice contextual information in MRI segmentation
- Evaluating segmentation performance in extreme few-shot scenarios
- Reducing dependency on large annotated medical imaging datasets

---

## Methodology

The framework includes:

- MRI preprocessing
- Foundation model adaptation
- Cross-slice contextual learning
- Few-shot segmentation evaluation
- Quantitative and qualitative analysis
